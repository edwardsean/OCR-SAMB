Jev's context vlm-first

One registry holds the combined field list (what the AI OCR reads on every page) and each document type's description (what Jev classifies with). The combined list always equals the union of every type's fields. A label on a practice page Jev missed becomes a lesson, and the teacher (GLM-4.6V-Flash, service vf-teacher) takes the lessons by itself, one at a time. It proposes one change; the change is replayed on the practice labels, and only one that helps reaches this screen, where a person approves or rejects it. Exam labels are never shown to the teacher. Versions are numbered "context #N" (not to be confused with pipeline v1).
