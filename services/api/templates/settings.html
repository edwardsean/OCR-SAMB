Model & kunci API

Three models do the AI work: the vision model for every call that sends a page image, the text model for every call that sends only text, and the classification model that decides each page's type. Each is an endpoint (any OpenAI-compatible API) and its API key, then a model chosen from that endpoint's list. Choose instruct (non-thinking) models: a thinking model writes a long hidden reasoning first, slow and paid for. They are set only here, never in .env: while one isn't set, no page is read (pages wait, then go on by themselves once it is). Saved here, used within seconds.
